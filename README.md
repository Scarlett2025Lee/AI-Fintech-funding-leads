# AI & Fintech Funding Leads

Weekly lists of recently funded AI and fintech startups — US + Europe only, pre-seed through Series B — curated for cold-email outreach by a PM/GTM/Data candidate.

## Local website

The [Signal website](web/README.md) is a local-first React + TypeScript workspace with a Node.js + SQLite backend. Its first slice includes sidebar navigation, a dashboard connected to SQLite, and the initial schema. See the [D-drive quick start](web/START_HERE.zh-CN.md) for Windows setup.

**Windows 下载：** [Signal.zip（直接下载）](https://github.com/Scarlett2025Lee/AI-Fintech-funding-leads/raw/refs/heads/codex/signal-web/downloads/Signal.zip)。解压到 `D:\`，得到 `D:\Signal`，双击 `Start-Signal.cmd`。等待显示网站地址后，双击 `Open-Signal.cmd`。首次运行需联网下载依赖；Windows 启动脚本尚未实机验证。详见[下载说明](downloads/README.md)。
